# TextCompressionTree
A project that shows a potential way of implementing a BinaryTree. My choice was to create a tree where nodes represent a chunk of a specified message that is "compressed" into binary bytes. This project is used as an example for students in ITSC 2214: Data Structures and Algorithms at UNC Charlotte under the guidance of Dr. Aileen Benedict.

You will not need to "pip install" any packages. All used packages are in standard Python libraries. This project was created on Python version: 3.13.3
